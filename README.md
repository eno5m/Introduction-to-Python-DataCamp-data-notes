# Data Exploration with NumPy

This project contains my practical exercises from the **Introduction to Python** course on DataCamp. It focuses on using NumPy arrays for data manipulation, cleaning, and statistical calculations.

## 📊 Exercises Completed
* Multi-dimensional array slicing
* Conditional logic and boolean masking for data filtering
* Unit standardization and conversions (Inches to Centimeters)
* Basic statistical modeling using correlation matrices (`np.corrcoef`) and center tendencies (`np.median`, `np.mean`)
